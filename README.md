# BioSocrates AI
### AI Database Engineer Project | AI + Database + AWS

BioSocrates AI is an AI-powered database system that can store, search, remember and answer from real data.

Built for banks, fintech, hospitals, and any company that needs AI to work with their data - fast and secure.

### What It Does
- AI Search: Ask question in normal English, AI finds answer from database
- RAG System: AI answers using YOUR data, not guessing
- Vector Database: Fast search for documents, customers, transactions
- Secure: Data protected, ready for UAE data residency rules

### Tech Stack
AI: Generative AI, RAG, LLMs, Bedrock, SageMaker
Database: PostgreSQL, DynamoDB, RDS, Vector DB
Cloud: AWS (me-central-1), Lambda, API Gateway, S3
Code: Python, SQL, Terraform
